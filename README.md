A personal portfolio website for a young developer building creative, playful, and thoughtful digital experiences.

- Portfolio: https://13sham.github.io/

## About

This project is a single-page portfolio designed to showcase my work, skills, and personality through a bold visual style. It blends a minimal dark aesthetic with motion, pixel-inspired typography, and a clean layout that feels modern and memorable.

I’m focused on front-end development, web design, and creative coding — turning ideas into engaging interfaces that are both functional and expressive.

## Tech stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Highlights

- Responsive single-page portfolio layout
- Dark mode visual design
- Animated hero and interactive UI details
- Skills showcase and personal branding
- Lightweight static site deployment

## Local preview

To run the site locally:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deployment

This portfolio is hosted using GitHub Pages and is optimized for simple, fast static hosting.
